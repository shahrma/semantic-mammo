# Mammography Semantic Feature Modulation

We train a ConvNeXt-Base classifier on region-of-interest (ROI) patches from mammography exams. BI-RADS semantic descriptors (breast density, mass shape, mass margins, calcification morphology, etc.) are incorporated into the backbone using a Conditional Layer Normalization (Cond-LN) semantic modulation mechanism.


The public release is expected early next week, starting October 04, 2026.
